# タイピングガーデン

打つほどキーボードのキーが外れ、外れたキーで作物を育てるタイピングゲームです。
ブラウザだけで動く1ファイル(`index.html`)のゲームで、GitHub Pages などにそのまま置いて遊べます。

## 遊び方

- **スコアアタック**(イージー / ノーマル / ハード): 60秒でどれだけキーを外せるか
- **タイムアタック**: 決まった数のことばを打ち終えるまでのタイム
- **一本勝負**: 1ミスで終了。進むほど長いことばが混ざる
- **キーボード農園**: タイピングで外したキーを通貨にして、作物を育てる。
  正しく打った1打ごとに、水の効いている作物の時間が進む
- **ことば図鑑**: 打ったことばが集まる
- **記録の引き継ぎ / ブラウザ間の同期**: 別のブラウザやスマホと記録を共有できる

スマホでは、タイピング以外(農園・ランキング・図鑑・記録の引き継ぎ)が遊べます。

## ことばを増やす

`index.html` の `WORDS_EASY` / `WORDS_NORMAL` / `WORDS_HARD` に追加します。

```js
{ t: "画面に出す表記", k: "にゅうりょくするひらがな" },
```

読み(`k`)の文字数で分けています: イージー 8文字以下 / ノーマル 9〜13文字 / ハード 14文字以上。

## Firebase の準備(ランキング・同期を使うとき)

Firebase を設定しなくても、ランキングと同期以外はすべて遊べます。

1. [Firebase コンソール](https://console.firebase.google.com/) で「プロジェクトを追加」し、新しいプロジェクトを作る(Google アナリティクスは不要)
2. 左のメニュー「構築」→「Realtime Database」→「データベースを作成」。場所は近い地域(例: シンガポール)、「ロックモード」で作成
3. 「ルール」タブを開き、このリポジトリの `database.rules.json` の中身を貼り付けて「公開」
4. プロジェクトの概要の「</>」(ウェブ)ボタンでアプリを登録し、表示される `firebaseConfig` の値をコピー
5. `index.html` の `const firebaseConfig = { ... }` にその値を貼り付ける(`databaseURL` が入っていることを確認)

`apiKey` などの値はブラウザに公開される前提のもので、秘密にする必要はありません。
書き込めるデータの形は `database.rules.json` で制限しています。

## GitHub Pages で公開する

リポジトリの Settings → Pages → Source を「Deploy from a branch」、ブランチを `main` / `(root)` にして保存します。
数分後に `https://<ユーザー名>.github.io/typing-garden/` で遊べます。
